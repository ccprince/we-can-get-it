# Play-test write-ups

One file per run, named `YYYY-MM-DD-<seed>.md`. Copy `TEMPLATE.md` and fill it in — including the
**Before the run** section, which is written *before* playing rather than recalled afterwards.

This practice is the single cheapest thing the prototype produced: it is the only reason a
retrospective could be written at the end of it (findings §5.4). A run without a write-up teaches
nothing twice.
